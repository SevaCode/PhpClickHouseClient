# Документация проекта

| Каталог | Назначение |
|---|---|
| [`roadmap/`](roadmap/) | Дорожная карта развития: этапы, задачи, статус выполнения. |
| [`adr/`](adr/) | Architecture Decision Records — зафиксированные архитектурные решения и их мотивация. |

## Правила

- Дорожная карта — единственный источник правды о статусе работ. Пункт отмечается `[x]`
  в том же PR, в котором он реализован, со ссылкой на PR.
- Любое решение, меняющее публичный API, поведение по умолчанию или зависимости,
  оформляется ADR (`adr/NNNN-краткое-название.md`, шаблон — [`adr/0000-template.md`](adr/0000-template.md)).
- Изменения, нарушающие обратную совместимость, не реализуются без отдельного согласования
  (см. [ADR-0001](adr/0001-backward-compatibility.md)).
