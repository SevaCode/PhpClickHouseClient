# ADR-0001: Политика обратной совместимости

- Статус: принято
- Дата: 2026-11-13

## Контекст

Библиотека опубликована на Packagist (`seva-code/php-click-house-client`) и используется
в проектах, которые обновляются через `composer update` в рамках `^1.x`.
Дорожная карта предполагает заметное расширение функциональности.

## Решение

В ветке 1.x допускаются только обратно совместимые изменения:

- не удаляются и не переименовываются публичные/protected классы, методы, свойства и константы;
- не меняются сигнатуры существующих публичных/protected методов
  (в т.ч. не добавляются параметры и типы возврата — это ломает наследников);
- не добавляются типы к существующим protected-свойствам;
- поведение по умолчанию (HTTP-метод, формат запросов, набор отправляемых параметров,
  тип и код выбрасываемых исключений) не меняется; новое поведение включается явно (opt-in);
- новые возможности добавляются новыми методами/классами;
- новые классы исключений наследуются от `ChcException`, чтобы существующие `catch` продолжали работать;
- поддерживаемые версии PHP и зависимостей можно только расширять.

Всё, что этим правилам не удовлетворяет, попадает в раздел «Требует согласования»
дорожной карты и реализуется только после явного одобрения владельца репозитория
(вероятнее всего — в 2.0).

## Последствия

Часть улучшений (строгие типы в сигнатурах, иммутабельный клиент, удаление устаревших
классов) откладывается. Новый API местами дублирует старый; старый помечается `@deprecated`
только после согласования.
